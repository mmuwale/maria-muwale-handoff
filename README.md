# Maria Muwale campaign site

Single scrolling, motion-first campaign site for a real candidate: **Maria Muwale, for
Female Academic Representative, Strathmore University.** Election **11 September 2026**,
voting 9:00 am to noon, results 1:30 pm.

Live at **https://maria-muwale.pages.dev**. This folder is that site, exactly as deployed.

There is **no build step**. `site/` is the deploy folder: two hand-authored HTML files, two
vendored JS files, an OG card and five icons. Nothing compiles, bundles or transpiles.

## Get it running

```
npm install
npm run serve
```

That prints a local URL. Open it. To reach it from a phone on the same network, use
`npm run serve:lan` instead.

## Then read, in this order

1. **`HANDOFF.md`** - what is here, what is deliberately not, the dependency chain, and how
   to send it back.
2. **`ARCHITECTURE.md`** - how the page works. Read this before you merge anything into
   `site/index.html`. It says what breaks when each piece is touched.
3. **`CONSTRAINTS.md`** - the rules that must survive the merge. Some are contractual with
   the candidate, some are technical. It says which is which.
4. **`KNOWN-ISSUES.md`** - defects and open judgement calls, each with the reasoning behind
   the decision not to fix it.
5. **`CONTENT.md`** - the copy, verbatim. Rearrange, never add.

## Layout

```
site/                 the deploy folder. Byte-identical to what is live.
  index.html          the campaign page. One file: markup, CSS and JS inline.
  manifesto.html      the manifesto. One file, one small script.
  vendor/             GSAP 3.12.5 and ScrollTrigger, vendored on purpose.
  og.jpg              share card, 1200x630
  favicon.ico favicon-16/32/48.png apple-touch-icon.png
assets/               real source material. Nothing here is generated by an AI.
  poster.jpeg         the campaign poster: the source of the palette and the type pairing
  photo-smiling.jpeg  studio photo, the hero portrait and the OG card come from this
  photo-side.jpeg     studio photo, unused in the shipped build
  derived/            the cut-outs and the crest crop
tests/
  resting.mjs         the 16-cell whole-page pass. This is the page's contract.
  baseline/baseline.json  the reference run to diff against
tools/
  make-og.mjs         rebuilds site/og.jpg
  cut-favicon.py      rebuilds the five icons from the crest
```

## The one thing to know before editing

The page renders three different ways: with GSAP, without GSAP, and under reduced motion.
All three are asserted by `npm test`. A change that only looks right in the first one is a
broken change. `ARCHITECTURE.md` explains why.
